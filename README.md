# 이야기 통역사 라이트 (DL Interpres Lite)

드림랜드(DreamLand)의 기본 번역은 그대로 쓰면서, **채팅마다** 따로 정한 내용을 번역 지시문에 자동으로 넣어 주는 확장입니다.
[ST-Interpres](https://github.com/tincansimagine/ST-Interpres)에서 아이디어를 얻었습니다.

- **용어집**: 고유명사를 늘 같은 말로 옮깁니다 (`Aldric = 알드릭`). 입력 번역(한→영)에서는 거꾸로 씁니다.
- **말투 카드**: 캐릭터별 존댓말/반말, 어미, 말버릇, 호칭을 고정합니다.
- **독자 지시문**: 번역할 때마다 지킬 요구를 적어 둡니다.
- **AI로 채우기**: 캐릭터 카드와 최근 대화 20개를 읽고 용어와 말투를 제안합니다. 이미 있는 항목은 건드리지 않습니다.
- **다른 채팅에서 가져오기**: 가지치기한 채팅이나 새 채팅으로 옮길 때 씁니다.

## 설치 · 업데이트

드림랜드 › 확장 › **URL로 설치**에 아래 주소를 넣습니다.

```
https://github.com/romantic-lamb/DL-interpres-lite/blob/main/index.js
```

새 버전이 나오면 같은 주소로 다시 설치하면 됩니다. 저장해 둔 용어집과 말투 카드는 그대로 남습니다.

## 쓰는 법

채팅 화면 › 장면 패널 › 도구 탭의 **이야기 통역사** 칸에서 편집합니다. 고친 내용은 바로 저장되고 번역 지시문에 반영됩니다.

## 동작 방식

드림랜드의 번역 지시문은 확장 매크로를 풀지 않습니다. 그래서 이 확장은 채팅을 열 때마다 **모든 번역 지시문 프리셋** 안에
`<!--interpres-lite-->` … `<!--/interpres-lite-->` 구간을 지금 채팅의 내용으로 갈아 끼웁니다.
구간은 `{{prompt}}`가 든 문단 바로 앞에 들어갑니다.

- 번역 › 지시문 프리셋 화면을 열면 이 구간이 보입니다. 지시문을 고칠 때 이 구간은 건드리지 마세요.
- 내용이 비어 있는 프리셋(앱 기본 지시문을 쓰는 것)은 건드리지 않습니다.
- 확장을 끄면 구간을 지워 프리셋을 원래대로 돌려 놓습니다.
